dataset includes \textbf{missing days} --- some dates are absent from
the data. Interestingly, in both datasets (\texttt{alr\_d},
\texttt{ing\_d}), the missing days are exactly the same.

\subsection{Linear Interpolation of Missing
Values}\label{linear-interpolation-of-missing-values}

The next step is to perform \textbf{linear interpolation} of the missing
data.

\subsubsection{Definition of Linear
Interpolation}\label{definition-of-linear-interpolation}

Linear interpolation is a method to estimate missing values by assuming
a linear change between two known points.

Mathematically, if a value \(y\) at position \(x\) is missing between
two known points \((x_0, y_0)\) and \((x_1, y_1)\), it is computed as:

\[
y = y_0 + \frac{y_1 - y_0}{x_1 - x_0} \cdot (x - x_0)
\]

\paragraph{Example}\label{example}

Consider the dataset:

\[
x = (3, 7, \text{NA}, 5, 8, \text{NA}, \text{NA}, 11)
\]

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  The first missing value (\texttt{NA}) is between 7 (position 2) and 5
  (position 4). Using the formula:
\end{enumerate}

\[
y = 7 + \frac{5 - 7}{4 - 2} \cdot (3 - 2) = 7 + (-1) = 6
\]

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\setcounter{enumi}{1}
\tightlist
\item
  The second missing value (\texttt{NA}) is between 8 (position 5) and
  11 (position 8). Since there are \textbf{two consecutive NAs}, we
  interpolate them linearly:
\end{enumerate}

\begin{itemize}
\tightlist
\item
  Position 6:
\end{itemize}

\[
y = 8 + \frac{11 - 8}{8 - 5} \cdot (6 - 5) = 8 + 1 = 9
\]

\begin{itemize}
\tightlist
\item
  Position 7:
\end{itemize}

\[
y = 8 + \frac{11 - 8}{8 - 5} \cdot (7 - 5) = 8 + 2 = 10
\]

After linear interpolation, the completed dataset becomes:

\[
x = (3, 7, 6, 5, 8, 9, 10, 11)
\]

\subsubsection{Using Build-In Functions}\label{using-build-in-functions}

I use the \texttt{approx} function in R for linear interpolation.

The \texttt{approx} function works as follows:

\begin{itemize}
\item
  It takes a vector of known points:

  \begin{itemize}
  \tightlist
  \item
    \texttt{x}: representing indexes of non-empty values,
  \item
    \texttt{y}: representing values at indexes at \texttt{x}.
  \end{itemize}
\item
  It computes values at target points (\texttt{xout}) through
  \textbf{linear interpolation}, i.e., it determines a point on the line
  connecting two neighboring known points.
\item
  The parameter \texttt{rule\ =\ 2} ensures that values outside the
  range of known points are \textbf{extrapolated} instead of returning
  NA.
\end{itemize}
